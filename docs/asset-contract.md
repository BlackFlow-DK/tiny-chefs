# Tiny Chefs prototype: asset contract

Working title "Tiny Chefs": co-op kitchen chaos where 1 m tall chefs work on a giant kitchen counter.
This file is the contract between the art agent (makes the .glb files) and the code agent (uses them).

Rules
- Sizes are Godot metres, X x Y x Z with Y up. Stay within 10% of them.
- Origin at base centre, resting on y=0 (see repo CLAUDE.md asset conventions).
- File: `game/assets/models/<name>.glb`, generated by `art/scripts/<name or family>.py`.
- Models are visuals only. The code defines all colliders from the sizes in this table, and falls back to a coloured primitive of the same size if a .glb is missing.
- Style: chunky low-poly, flat saturated colours, no textures. Each item must be recognisable at a glance from a camera high above and ~25 m away.
